### METHOD 1: cPanel (RECOMMENDED - EASIEST)

```
https://yourdomain.com:2083

https://your-cpanel-url/cpanel
```

**Step 3: Jika Addon Domains:**
```
New Addon Domain:
├─ New Domain Name: services.bsdgs.fun
├─ Domain: bsdgs.fun (pilih dari dropdown)
├─ Subdomain: services
└─ Document Root: public_html/EcoProvider/public
```

**Click:** Add Domain

**Step 4: Jika Subdomains:**
```
Create Subdomain:
├─ Subdomain: services
├─ Domain: bsdgs.fun
└─ Document Root: public_html/EcoProvider/public
```

**Click:** Create

**Step 5: Wait for DNS**
- DNS propagation: 1-5 minutes
- Sometimes: 24 hours globally

**Step 6: Verify in cPanel**
- Go to: **Addon Domains** atau **Subdomains**
- Should see: `services.bsdgs.fun` listed

### METHOD 2: SSH / Command Line

**Step 1: SSH to Hosting**
```bash
ssh user@yourdomain.com
# or
ssh user@hosting-ip
```

**Step 2: Navigate to Apache Config**
```bash
# For cPanel (typical):
cd /etc/apache2/conf.d/userdata/std/2_4

# List available configs:
ls -la

# You should see files like:
# yourdomain.com_version.conf
# yourdomain.com.conf
```

**Step 3: Create/Edit Subdomain Config**

**For cPanel - Create New File:**
```bash
# Create config file for subdomain
nano /etc/apache2/conf.d/userdata/std/2_4/yourdomain.com/services.conf

# Add content below:
```

**Config Content:**
```apache
# services.bsdgs.fun Configuration
<VirtualHost *:80>
    ServerName services.bsdgs.fun
    ServerAlias services.bsdgs.fun
    DocumentRoot /home/username/public_html/EcoProvider/public
    
    <Directory /home/username/public_html/EcoProvider/public>
        AllowOverride All
        Order allow,deny
        Allow from all
        
        # Enable rewrite for Laravel routing
        <IfModule mod_rewrite.c>
            RewriteEngine On
            RewriteBase /
            RewriteCond %{REQUEST_FILENAME} !-f
            RewriteCond %{REQUEST_FILENAME} !-d
            RewriteRule ^(.*)$ index.php?/$1 [L]
        </IfModule>
    </Directory>
    
    # Redirect HTTP to HTTPS
    RewriteEngine On
    RewriteCond %{HTTPS} off
    RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
</VirtualHost>

# HTTPS Configuration
<VirtualHost *:443>
    ServerName services.bsdgs.fun
    ServerAlias services.bsdgs.fun
    DocumentRoot /home/username/public_html/EcoProvider/public
    
    # SSL Certificate (auto-generated by Let's Encrypt)
    SSLEngine on
    SSLCertificateFile /etc/ssl/certs/services.bsdgs.fun.crt
    SSLCertificateKeyFile /etc/ssl/private/services.bsdgs.fun.key
    SSLCertificateChainFile /etc/ssl/certs/services.bsdgs.fun.ca-bundle
    
    <Directory /home/username/public_html/EcoProvider/public>
        AllowOverride All
        Order allow,deny
        Allow from all
        
        # Enable rewrite for Laravel routing
        <IfModule mod_rewrite.c>
            RewriteEngine On
            RewriteBase /
            RewriteCond %{REQUEST_FILENAME} !-f
            RewriteCond %{REQUEST_FILENAME} !-d
            RewriteRule ^(.*)$ index.php?/$1 [L]
        </IfModule>
    </Directory>
</VirtualHost>
```

**Save:** Ctrl+X → Y → Enter

**Step 4: Rebuild Apache Config**
```bash
# For cPanel:
/usr/local/cpanel/bin/build_apache_conf

# Output:
# Fixing /var/cpanel/apache/httpd.conf...
# Done
```

**Step 5: Restart Apache**
```bash
# Restart Apache
systemctl restart apache2
# or
systemctl restart httpd
# or
service apache2 restart

# Verify
systemctl status apache2
```

**Step 6: Setup SSL Certificate**

**Option A: AutoSSL (Recommended)**
```bash
# Go to cPanel: AutoSSL
# Or via CLI:
cd /usr/local/cpanel/bin
./autossl_check

# Wait 5-10 minutes for certificate
```

**Option B: Manual with Let's Encrypt**
```bash
# Install Certbot
apt-get install certbot python3-certbot-apache
# or
yum install certbot python3-certbot-apache

# Generate certificate
certbot certonly --apache -d services.bsdgs.fun

# Follow prompts...
# Certificate will be saved to:
# /etc/letsencrypt/live/services.bsdgs.fun/
```

## ⚠️ TROUBLESHOOTING SUBDOMAIN

### Problem: Subdomain Still Not Working After 24h

```bash
# SSH: Force Apache config rebuild

# For cPanel:
/usr/local/cpanel/bin/build_apache_conf
systemctl restart apache2

# For standard:
apache2ctl configtest
# Should output: Syntax OK

systemctl restart apache2
```

### Problem: 404 Error on Subdomain

```bash
# Cause: DocumentRoot wrong or .htaccess issue

# SSH:

# 1. Verify DocumentRoot
grep DocumentRoot /etc/apache2/conf.d/userdata/std/2_4/yourdomain.com/services.conf

# Should show:
# DocumentRoot /home/username/public_html/EcoProvider/public

# 2. Check folder exists
ls -la /home/username/public_html/EcoProvider/public/

# 3. Verify .htaccess
cat /home/username/public_html/EcoProvider/public/.htaccess

# 4. Check rewrite module
apache2ctl -M | grep rewrite

# If not enabled:
a2enmod rewrite
systemctl restart apache2
```

### Problem: SSL Certificate Not Applying

```bash
# SSH:

# Check certificate files exist
ls -la /etc/ssl/certs/services.bsdgs.fun*

# If not, regenerate:
certbot certonly --apache -d services.bsdgs.fun

# Or use AutoSSL in cPanel (recommended)
/usr/local/cpanel/bin/autossl_check
```

### Problem: Redirects to Wrong Domain

```bash
# SSH: Check for hardcoded redirects in code

# In EcoProvider project:
grep -r "localhost:8001\|old-domain" app routes config

# Fix any hardcoded URLs to:
https://services.bsdgs.fun

# Also check .env:
cat .env | grep APP_URL
# Should be: APP_URL=https://services.bsdgs.fun
```
