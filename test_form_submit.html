Test Form Submit Reward Item

Format: JPG, PNG, GIF (Max 2MB)

Cara menggunakan:

  1. Login sebagai admin di browser
  2. Buka halaman admin/reward-items
  3. Buka Developer Tools (F12) → Console
  4. Ketik: document.querySelector('meta[name="csrf-token"]').content
  5. Copy token yang muncul
  6. Paste di field "_token" di atas (ganti PASTE_YOUR_CSRF_TOKEN_HERE)
  7. Isi form dan submit
